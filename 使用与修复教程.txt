守望先锋 × 微信：Alt+A 截图冲突使用与修复教程
版本：1.0 | Windows 10 / Windows 11

一、为什么需要这个脚本

玩守望先锋时，微信常常也挂在后台。选威能用 Alt 配合左右键，
这时如果还按着 A 移动，就容易碰到微信默认的 Alt+A 截图。
截图框一弹出来，游戏卡一下，原本的操作也被打断。

这个脚本用来临时拦住这组按键：玩之前双击开启，打完双击恢复。
切出去回消息或看浏览器时，截图照常用，不用反复改微信快捷键。

日常只用下面两个 BAT 文件，不需要额外安装软件，也没有 EXE。

01_关闭游戏内截图快捷键.bat
  开启保护。只在 Overwatch.exe 是当前前台程序时屏蔽 Alt+A。
  游戏使用窗口、无边框或全屏模式都可以；判断依据是前台进程。
  切到桌面、微信、浏览器或其他程序后，Alt+A 自动放行。

02_恢复截图快捷键.bat
  停止本工具的后台脚本，卸载按键拦截，恢复正常输入。
  重复运行恢复脚本也可以，不会关闭游戏或微信。

这里“关闭”的意思是关闭游戏内的 Alt+A 截图触发，不是关闭微信。

二、日常使用

1. 先把压缩包完整解压到一个普通、可写的文件夹，例如桌面。
   不要直接在压缩包预览中运行。
2. 打开微信后，双击“01_关闭游戏内截图快捷键.bat”。
3. 看到绿色“已开启”提示后，命令窗口会自动关闭。
   然后进入游戏。后台会有一个 powershell.exe 进程负责临时保护。
4. 游戏刚启动时，等待约 1 秒，让脚本识别进程。
5. 游戏结束后，双击“02_恢复截图快捷键.bat”。
   看到绿色“已恢复”提示，表示本工具已经停止。

开启脚本窗口自动关闭属于正常现象，保护仍在后台运行。
重复双击开启脚本不会叠加多个拦截实例，也不会重新安装拦截。
如需修复拦截，请先恢复，再开启。
重启或注销当前 Windows 会话后，保护自动结束；下次需要时重新开启。
不设置开机启动，不创建计划任务或服务。

三、一分钟自检

1. 先在桌面确认微信原来的 Alt+A 截图本来可以使用。
2. 运行开启脚本，进入守望先锋的练习场或菜单。
3. 按平时的顺序，先按住 A 移动，再按 Alt 配合左右键选威能。
   看看微信截图是否还会弹出，同时确认移动和选择操作是否正常。
   再试一次先按 Alt、后按 A，两种顺序都检查一下。
4. 单独按 A，或使用 Alt+Tab：预期正常。
5. 松开 A、Alt 后切到桌面，再按 Alt+A：预期正常截图。
6. 运行恢复脚本，再回游戏测试：本工具应不再拦截。

这套脚本拦截的是 Alt+A 组合本身，不是仅取消微信的某项内部功能。
先按 A 再按 Alt 时，已经放行的 A 按下事件会保留，松开也会放行。
如果先按 Alt 再按 A，游戏可能收不到 A 的按下事件。
请按自己的操作习惯试一下；如果影响移动或选威能，双击恢复即可。
单独的 A、单独的 Alt、Alt+Tab、Alt+F4 均不在屏蔽规则中。
带 Ctrl、Shift 或 Windows 键的其他组合也不在屏蔽规则中。
按住 A 跨窗口或增减修饰键时，先全部松开再测试，避免把一次长按当成新的按键。

四、为什么用 BAT，没写注册表

Windows 的常见 Scancode Map 注册表映射用于单键映射，不能用来表达
“仅 Overwatch.exe 在前台时，拦截 Alt+A 组合”这个条件。
用它禁用 A 或 Alt 会影响其他场景，也不能保留本需求中的自动恢复行为。

所以这两个 BAT 使用系统自带 Windows PowerShell 5.1，在后台调用 Windows
键盘钩子，并按游戏进程和前台窗口决定是否拦截。
BAT 中的 C# 源码由 PowerShell 的 Add-Type 加载，不分发新的 EXE。
不会写注册表，不改微信配置，不读写游戏内存，不注入游戏进程，不模拟按键。
只记录启动、停止、错误和拦截次数，不记录你输入的文字。

命令中的 -ExecutionPolicy Bypass 只影响该次 PowerShell 进程，
不会永久更改系统执行策略；组织强制的脚本策略仍可能阻止运行。

五、失效了怎么修复

A. 首选：重新开启拦截

1. 双击“02_恢复截图快捷键.bat”，等到提示已恢复。
2. 确认微信已经打开。
3. 再双击“01_关闭游戏内截图快捷键.bat”。
4. 进入游戏等待约 1 秒，按“一分钟自检”验证。

微信重启、其他快捷键工具抢先处理按键，或系统撤销超时钩子，都可能影响拦截。
重新运行“恢复 → 开启”会重新安装本工具的钩子。
如果装有其他键盘映射工具，可先暂停其中的冲突规则，再验证。
不要同时运行多个来源的 Alt+A 屏蔽脚本。

B. 游戏以管理员身份运行，脚本却没有

先正常运行恢复脚本。右键开启 BAT，选择“以管理员身份运行”，再测试。
以后恢复也使用同一 Windows 账户、同样的权限运行恢复 BAT。
仅在普通运行无效且游戏/微信确实使用了更高权限时尝试这一项。

C. 游戏更新以后识别不到

1. 保持游戏运行，打开任务管理器的“详细信息”页。
2. 找到真正的游戏进程，查看名称，通常为 Overwatch.exe。
   不要把 Battle.net.exe 或游戏启动器当成游戏进程。
3. 如果实际名称确实改变，先运行恢复脚本。
4. 右键“01_关闭游戏内截图快捷键.bat”，用记事本编辑，搜索下面一行：

   $TargetProcessNames = @('Overwatch')

5. 把引号中的 Overwatch 改成实际进程名称，去掉最后的 .exe。
   例如实际名称为 ExampleGame.exe，就写 @('ExampleGame')。
   保存为 UTF-8，保留 .bat 扩展名，然后重新开启并测试。
6. 若编辑后出错，重新解压原始压缩包即可恢复脚本本身。

D. 双击后报错、窗口闪退、或没有出现“已开启”

1. 确认已完整解压，并且文件名结尾是 .bat，不是 .bat.txt。
2. 移到桌面等可写文件夹。右键 BAT 选择“编辑”，也可确认内容未被截断。
3. 查看同目录“运行日志.txt”。启动失败通常会有 LAUNCH ERROR 或 WORKER ERROR。
4. 保留错误文本，按原样反馈；不要先去删注册表或重置微信数据。
5. 需要 Windows 自带的 Windows PowerShell 5.1 和 .NET Framework。
   Windows 10/11 通常已有这些组件，不需要安装 Python 或 AutoHotkey。
6. 如果组织策略禁止脚本或 Add-Type，请联系管理员；本教程不要求绕过这些策略。

E. 点击恢复后仍不正常：强制恢复

1. 如果之前用管理员权限开启，就用管理员权限运行恢复 BAT。
2. 仍提示后台未退出时，保存手头工作，然后注销 Windows 或重启电脑。
   这样会结束本工具的临时后台进程。由于没有持久映射，无需注册表回滚。
3. 如果不方便重启，也可在任务管理器“详细信息”中开启“命令行”列。
   只结束命令行明确包含 OW_ALT_A_GUARD_WORKER 的 powershell.exe。
   运行日志中 START PID= 后的编号可作辅助核对，但旧 PID 可能被复用，
   必须同时检查命令行，不能只按旧编号结束进程。
   不要结束全部 PowerShell 进程，也不要结束游戏或微信进程。
4. 松开 Alt、A，再各按一次。如果恢复后微信本身仍不能截图，重启微信，
   检查微信截图快捷键是否仍为 Alt+A，以及是否被其他程序占用。

恢复脚本只撤销本工具的临时屏蔽，不会替你恢复其他软件改过的设置。
本工具没有注册表映射，因此不要为了修复它去删除 Scancode Map 或其他注册表值。

六、彻底移除

先运行恢复脚本，或注销/重启 Windows。之后删除解压出的文件夹即可。
运行日志.txt 和运行日志.txt.old 只是本地诊断日志，也可一并删除。
不会有需要卸载的服务、驱动、计划任务或开机启动项。

七、验证范围与技术参考

已有验证包括 43 项按键规则，以及开启、重复开启、停止、重复停止检查。
这些检查能验证脚本逻辑，但还没有完成真实守望先锋与微信同时运行的兼容性测试。
实际守望先锋、微信版本和游戏输入方式仍需按第三节自检。
脚本不承诺兼容所有游戏输入模式；若组合键导致游戏操作缺失，请运行恢复脚本。
